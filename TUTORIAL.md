## 1. Введение

**СОВА** — это инструмент для геовизуализации топонимов из нарративных текстов и таблиц. Программа позволяет превращать упоминания мест в интерактивную карту с таймлайном, анимировать маршруты во времени и создавать пространственно-эксплицитные модели.

Этот туториал проведёт вас через полный цикл работы: от загрузки исходного текста до экспорта готовой карты. Документ рассчитан на исследователей, преподавателей, студентов и всех, кто работает с текстами и географией, независимо от уровня технической подготовки.  
  
**Скачайте файл SOVA_0.4, откройте его в браузере, либо [откройте программу "СОВА" в браузере](https://matrixmentularia.github.io/SOVA/SOVA_0.4.html), нажмите на кнопку "Промпты", скопируйте промпт "РУКОВОДСТВО", вставьте в ваш ИИ-чат, далее следуйте указаниям.**  
[Пример 1 готовой интерактивной карты, сделанной в Сове](https://matrixmentularia.github.io/SOVA/examples_text_set/tt1.map_export.sova.html)  
[Пример 2 готовой интерактивной карты, сделанной в Сове](https://matrixmentularia.github.io/SOVA/examples/Mainichi.map_export.sova.html)  

**Что вы научитесь делать:**
- Загружать и нормализовать текст
- Использовать ИИ для первичной разметки топонимов
- Проверять и редактировать результаты разметки
- Получать и править координаты
- Строить карту и анимировать её по времени
- Экспортировать результат в разных форматах

## 2. Подготовка к работе

Перед началом работы убедитесь, что у вас есть:

### 2.1. Необходимое окружение

- **Современный браузер** — Chrome или Яндекс.Браузер (рекомендуется). Firefox также поддерживается. В старых версиях Edge возможны проблемы с кодировкой.
- **Файл программы** — `SOVA_0.4.html`, который можно скачать из репозитория проекта.
- **Интернет** — нужен только для первой загрузки картографической подложки. После этого программа может работать офлайн.

### 2.2. Дополнительные инструменты

Для комфортной работы вам также понадобятся:

- **Блокнот** (или любой текстовый редактор) — для сохранения фрагментов текста и JSON-файлов, которые будет выдавать ИИ. Это ваш «страховочный» инструмент: если что-то пойдёт не так, у вас останутся промежуточные результаты.
- **ИИ-ассистент** — Qwen, Kimi, DeepSeek или другой. СОВА не привязана к конкретной модели, но для разных ИИ могут потребоваться разные подходы к промптам.

### 2.3. Ваши данные

В зависимости от задачи, у вас может быть:
- **Текст** (`.txt`) — исторический документ, путевые заметки, художественный текст, новости и т.д.
- **Таблица с топонимами** — если у вас уже есть готовые данные, программу можно использовать без текста.

## 3. Пошаговый рабочий процесс

Работа с СОВОЙ состоит из шести основных этапов. Вы можете проходить их последовательно или возвращаться к предыдущим шагам по мере необходимости.

### Шаг 1. Загрузка и нормализация текста

Первое, что нужно сделать — загрузить исходный текст в программу.

1. Откройте файл `SOVA_0.4.html` в браузере.
2. Нажмите кнопку **«Текст.txt»** в верхней панели или перетащите файл в рабочую область.
3. Программа автоматически нормализует текст: удалит невидимые артефакты, приведёт к единому формату символы переноса строки и пробелов.

> **Почему это важно?** Если подать текст в ИИ напрямую, разница в типографике (разные виды пробелов, переносов, кавычек) может сбить разметку. СОВА заранее приводит текст к единообразию, чтобы якоря (текстовые привязки) работали корректно.

#### Если текст длинный

Если ваш текст длиннее 7000 символов, программа покажет предупреждение и порекомендует обрабатывать его частями. Это не ограничение — вы можете продолжить работать с полным текстом, но обработка частями даёт более точный результат.

**Как фрагментировать текст:**

1. Выделите нужный фрагмент в окне текста (клик в начале → скролл → Shift+Click в конце).
2. Нажмите кнопку **«Копировать фрагмент»**.
3. Сохраните скопированный фрагмент в отдельный `.txt` файл в блокноте — это поможет не потерять прогресс.
4. Повторите для всех частей текста.

> **Совет:** Оптимальная длина фрагмента определяется опытным путём и зависит от насыщенности текста топонимами. Для плотных исторических документов может хватить 2000–3000 символов, для художественных текстов — 5000–7000.

### Шаг 2. Работа с ИИ: первичная разметка

Теперь нужно получить от ИИ список топонимов с их привязкой к тексту. Для этого в СОВЕ есть встроенные промпты.

#### 2.1. Выбор промпта

Нажмите кнопку **«Промпты»** в верхней панели. Вы увидите четыре варианта:  
- **РУКОВОДСТВО** — промпт для ИИ-ассистента по программе СОВА. Ему можно будет задавать вопросы по работе программы для экономии времени и нервов. Копируем, загружаем в ваш ИИ (рекомендован Qwen), следуем указаниям, задаём вопросы. Также можно будет загрузить туда файл программы, но для этого возможно придётся пересохранить его в формат тхт через блокнот.
- **Геопарсинг универсальный** — основной промпт для поиска топонимов в тексте. Работает через текстовые якоря (привязку к конкретным словам). **Рекомендуется для большинства случаев.**
- **Таблица в СОВУ** — для случаев, если у вас есть таблица в любом формате и вы хотите на её основе сделать карту в СОВЕ. При помощи этого промпта ИИ сделает из вашей таблицы сова-читаемый формат.
- **Геокодирование** — используется на следующем этапе, для получения координат уже найденных топонимов.
- **Время** — для извлечения дат из текста.

Для первого этапа вам нужен **«Геопарсинг универсальный»**.

#### 2.2. Получение разметки от ИИ

1. Скопируйте текст промпта (кнопка **«📋 Копировать»**).
2. Откройте чат с вашим ИИ-ассистентом.
3. Вставьте промпт, а затем — текст (целиком или фрагмент).
4. Отправьте запрос и дождитесь ответа.

ИИ выдаст результат в виде JSON-файла или текста, который нужно сохранить как JSON.

#### 2.3. Сохранение результата

Если ИИ выдал готовый JSON — отлично, просто скопируйте его.

Если ИИ выдал «полотно текста» с JSON внутри:

1. Скопируйте весь ответ.
2. Откройте блокнот.
3. Вставьте текст.
4. Нажмите **«Сохранить как»** → выберите тип файла **«Все форматы»**.
5. Назовите файл, например: `fragment1.markup.sova.json`.
6. Сохраните.

> **Важно:** Расширение `.json` обязательно. Имя файла может быть любым, но программа ожидает именно JSON-формат внутри.

#### 2.4. Примеры идеальных JSON

В репозитории проекта лежат примеры правильно отформатированных JSON-файлов. Если ваш ИИ выдаёт результат в неожиданном формате, загрузите ему пример и попросите «сделать как в образце».

### Шаг 3. Загрузка разметки и работа во вкладке «Текст»

#### 3.1. Загрузка JSON

Нажмите кнопку **«Разметка.json»** и выберите файл, полученный от ИИ.

Если у вас уже есть разметка, программа спросит: **«Загрузить»** или **«Склеить»**.
- **Загрузить** — заменит старую разметку новой.
- **Склеить** — добавит новую разметку к существующей (удобно, если вы обрабатывали текст частями).

> **Совет:** В Сову не нужно загружать фрагменты текста — загружайте текст целиком, а разметки фрагментов склеивайте между собой. Фрагментировать нужно только для удобства обработки в ИИ.

#### 3.2. Интерфейс вкладки «Текст»

После загрузки вы увидите:
- **Слева** — полотно текста с выделенными топонимами.
- **Справа** — таблицу с найденными вхождениями.

Между ними работает **синхроскролл**: при прокрутке текста таблица прокручивается параллельно, и наоборот. Клик по вхождению в тексте или таблице прокручивает оба окна к этому месту.

[Скриншот: Вкладка «Текст» с выделенными топонимами и таблицей справа]

#### 3.3. Статусы вхождений

Каждый топоним в таблице имеет статус:

- **✅ Подтвердить** — вхождение корректно, оно попадёт на карту.
- **🤔 Уточнить** — пометка для себя (например, «вернусь к этому позже»). Такие вхождения всё равно попадают на карту.
- **❌ Отклонить** — вхождение не нужно, оно не попадёт на карту.

Статус можно менять:
- Через выпадающий список в таблице.
- Через контекстное меню (правая кнопка мыши) прямо в тексте.

> **Важно:** Отклонённое вхождение не удаляется — его всегда можно вернуть, просто поменяв статус. Чтобы отклонённые не мешали, можно отключить их отображение в таблице.

#### 3.4. Ручная работа с топонимами

Если ИИ что-то пропустил или выделил неверно, вы можете работать вручную:

**Добавить топоним:**
1. Выделите мышью фрагмент текста (до 30 символов).
2. Появится всплывающая кнопка **«➕ Добавить топоним»**.
3. Нажмите её — вхождение добавится в таблицу, все сопутствующие данные заполнятся автоматически.

**Привязать к выделению** (для «холостых» топонимов):
Холостые топонимы — это те, которые по какой-то причине не привязались к тексту. В таблице они есть, но связи с текстом нет. Чтобы привязать:

1. Кликните на строку в таблице.
2. Нажмите кнопку **«🔗 Привязать к выделению»**.
3. Выделите нужный фрагмент в тексте.
4. Нажмите всплывающую кнопку **«Привязать топоним»».

Если выделить слишком много, появится кнопка «Копировать фрагмент» — это нормально. Ограничений на перепривязку нет.

[Скриншот: Всплывающая кнопка «Привязать топоним» при выделении текста]

### Шаг 4. Геокодирование: получение координат

Теперь нужно получить координаты для всех подтверждённых топонимов. Есть два подхода:

#### Подход А: Геокодировать всё сразу

1. Скачайте «чистый» файл (кнопка **«🧹 Чистый (без отклонённых)»**) — это сэкономит мощность ИИ.
2. Скопируйте промпт **«Геокодирование»** из раздела промптов.
3. Отдайте ИИ чистый файл вместе с промптом.
4. Получите JSON с координатами.
5. Загрузите его через кнопку **«Данные.json»**.

#### Подход Б: Работать с координатами вручную

Если ИИ выдаёт неточные координаты (а это бывает часто), вы можете править их прямо в программе:

**Способ 1. Перетаскивание маркера на карте:**
1. Перейдите на вкладку **«Карта»**.
2. Постройте карту.
3. Перетащите маркер в нужное место — координаты в таблице пересчитаются автоматически.

**Способ 2. Через центр карты:**
1. На карте есть метка — **красный крестик** в центре.
2. Подвиньте карту так, чтобы нужное место оказалось под крестиком.
3. В окне над строкой поиска в сайдбаре появятся координаты этого места.
4. Скопируйте их (выделить + Ctrl+C или кнопка **«Копи»**).
5. Вставьте в поле координат в таблице на вкладке «Текст».
6. Перестройте карту, чтобы увидеть изменения.

**Способ 3. Ввод вручную:**
Просто впишите нужные координаты в поле `lat` и `lon` в таблице.  

**Способ 4. Используйте Поиск:**
Напишите нужное название в строку Поиск, нажмите Enter или значок Лупа, выберите нужное из выпадающего списка. Удостоверьтесь на карте, что это нужная вам точка. Скопируйте координаты из строки координат, вставьте в поле в таблице на странице Текст.

[Скриншот: Красный крестик в центре карты и окно с координатами в сайдбаре]

#### Поиск на карте

В сайдбаре карты есть строка поиска. Она ищет места на реальной картографической подложке (OpenStreetMap) — полезно, если вы добавляете вручную локации и хотите быстро найти нужное место. Поиск по пользовательским точкам пока не работает.

### Шаг 5. Работа с датами и группами

#### 5.1. Форматы дат

Программа поддерживает разные форматы дат:
- Только год: `1812`
- Год и месяц: `1812-09`
- Полная дата: `1812-09-14`
- С временем: `1812-09-14T10:30:00`

Если дат нет, программа показывает события в порядке, заданном текстом (или таблицей, если работаете без текста). За порядок воспроизведения без даты отвечает редактируемое поле Order.

#### 5.2. Линии на карте

Если у точек есть даты, программа автоматически рисует **линии между датированными точками** — это позволяет видеть маршрут. Если дат нет, а только порядок в тексте, линии не рисуются. Пока линии не отключаются, в дальнейшем эта опция появится.

#### 5.3. Группы

Поле `group` в таблице используется для цветовой маркировки на карте. Цвета назначаются автоматически и пока не настраиваются (эта функция появится в будущих версиях). Группы помогают визуально разделять разные категории топонимов (например, «Города», «Сражения», «Реки»). Поле редактируемое, можно воспользоваться идеями ИИ или задать свои группы.

#### 5.4. Поле order (порядок)

Порядок вхождений автоматически определяется по позиции неотклонённых вхождений в тексте и пересчитывается при каждом изменении в таблице. Поле `global_id` на отклонённые не реагирует. Вручную порядок менять можно, но при следующем изменении в таблице он пересчитается.

### Шаг 6. Вкладка «Карта»: построение и анимация

#### 6.1. Построение карты

1. Перейдите на вкладку **«Карта»**.
2. Данные загрузятся из таблицы автоматически.
3. Нажмите кнопку **«🔨 Построить карту»**.

[Скриншот: Вкладка «Карта» с построенной визуализацией]

#### 6.2. Режимы анимации

В настройках есть два режима:

- **События** — анимирует события с заданным промежутком времени между точками. Показывает, в каком порядке они произошли. Динамику можно увидеть только по расположению точек на таймлайне.
- **Время** — показывает события не только в хронологии, но и в реальном времени, то есть отображает реальную динамику. Заданный промежуток — это реальный фрагмент времени, в котором может быть много событий, а может ни одного.

**Сек/шаг** — длительность одного шага анимации в секундах.

**Стоп-зум** — если при анимации зум становится некомфортным (например, карта слишком сильно приближается), программа автоматически останавливается на этом уровне.

#### 6.3. Управление анимацией

- **▶ Играть** — запустить анимацию.
- **↺ Сброс** — вернуть анимацию в начало.
- Ползунок можно перетаскивать вручную, чтобы быстро перейти к нужному моменту.

#### 6.4. Экспорт HTML-карты

Кнопка **«📤 Код для сайта»** (дублируется в меню **«Скачать»**) позволяет скачать автономную HTML-страницу с готовой картой. На этой странице тоже будет таймлайн и таблица вхождений.

Вы можете:
- Вклеить эту страницу на свой сайт через `<iframe>`.
- Открыть её локально (потребуется интернет для подгрузки подложки).
- Делать с ней всё, что захочется.

> **Важно:** Экспортированная HTML-карта требует интернета для загрузки картографической подложки. Без интернета точки будут «висеть в воздухе».

## 4. Сохранение и безопасность

### 4.1. Как сохраняется работа

Программа **не сохраняет данные автоматически**. Перед закрытием вкладки или перезагрузкой появляется предупреждение о том, что данные могут быть утрачены.

Чтобы сохранить прогресс:
1. Нажмите кнопку **«💾 Проект (полный)»**.
2. Скачается файл `.sova.json` со всем текущим состоянием.

### 4.2. Итеративное сохранение

Каждый раз, когда вы скачиваете проект, создаётся **новый файл**. Старый файл не перезаписывается. Это позволяет:
- Отслеживать итерации работы.
- Легко возвращаться к предыдущим состояниям.
- Иметь своеобразный «авто-бэкап на минималках».

> **Совет:** Перед загрузкой новых данных (разметки или геокодирования) всегда скачивайте полный файл проекта. Если что-то пойдёт не так, вы сможете откатиться.

### 4.3. Приватность данных

Программа работает **полностью локально** в браузере. Она не отправляет ваши данные на внешние серверы и не требует регистрации. Интернет нужен только для подгрузки картографической подложки.

## 5. Частые вопросы и решение проблем (FAQ)

### ❓ ИИ выдал JSON, но программа его не загружает

**Что проверить:**
- Убедитесь, что файл действительно имеет расширение `.json`.
- Откройте файл в блокноте — он должен начинаться с `{` или `[`.
- Проверьте, что в шапке файла указан правильный формат (это прописано в промптах).

**Что делать:**
- Загрузите ИИ пример идеального JSON из репозитория и попросите «сделать как в образце».
- Попробуйте другой промпт (например, универсальный вместо числового).

### ❓ Точки не появляются на карте

**Что проверить:**
- Загружены ли координаты (через «Данные.json» или вручную).
- Не все ли вхождения отклонены.
- Нажали ли вы кнопку «Построить карту».

**Что делать:**
- Проверьте, что в таблице есть значения в полях `lat` и `lon`.
- Убедитесь, что хотя бы одно вхождение имеет статус «Подтверждено» или «Уточнить».

### ❓ Текст не синхронизируется с таблицей

**Что проверить:**
- Включена ли функция синхроскролла (кнопка **«🔗 Синхроскролл»** в верхней панели).
- Корректно ли загружена разметка (есть ли привязка к тексту).

**Что делать:**
- Если вхождения «холостые» (не привязаны к тексту), привяжите их вручную через кнопку «Привязать к выделению».

### ❓ Координаты неправильные (точка в океане)

**Что делать:**
- Отредактируйте координаты вручную одним из способов, описанных в Шаге 4 (перетаскивание маркера, через красный крестик, ввод вручную).

### ❓ Программа тормозит на большом тексте

**Что делать:**
- Искусственных ограничений нет, но производительность зависит от железа. Если текст очень большой (более 300 000 символов), попробуйте работать с ним по частям.

### ❓ Сломалось что-то непонятное

**Главное правило: Don't panic!**

Программу совсем сломать невозможно. Если что-то пошло не так:
1. Перезагрузите страницу в браузере.
2. Загрузите последний сохранённый файл проекта.
3. Продолжите работу.

Если проблема повторяется — напишите автору на marvsh@yandex.ru, приложив файл проекта и описание действий.

## 6. Глоссарий: поля таблицы

Краткая шпаргалка по колонкам таблицы топонимов:

| Поле | Описание | Пример |
|------|----------|--------|
| `name` | Название топонима | `Москва` |
| `lat` | Широта | `55.7558` |
| `lon` | Долгота | `37.6173` |
| `date` | Дата события (YYYY-MM-DD или упрощённые форматы) | `1812-09-14` |
| `order` | Порядок воспроизведения (автоматический) | `1`, `2`, `3` |
| `group` | Группа для цветовой маркировки | `Сражения` |
| `description` | Описание / комментарий | `Бородинское сражение` |
| `status` | Статус вхождения | `✅`, `🤔`, `❌` |

## 7. Альтернативные сценарии работы

### 7.1. Работа только с текстом (без ИИ)

Вы можете загружать только текст и размечать топонимы вручную:
1. Загрузите `.txt`.
2. Выделяйте фрагменты текста и нажимайте «➕ Добавить топоним».
3. Заполняйте координаты вручную.
4. Стройте карту.

### 7.2. Работа только с таблицей (без текста)

Если у вас уже есть готовые данные, текст не обязателен:
1. Загрузите разметку или данные напрямую.
2. Все топонимы будут «холостыми» (без привязки к тексту), но это не влияет на карту.
3. Работайте с таблицей и стройте карту.

### 7.3. Преобразование существующей таблицы в формат СОВЫ

Если у вас есть таблица в другом формате, вы можете попросить ИИ преобразовать её в формат СОВЫ. Используйте готовый файл разметки как образец и попросите нейросеть «сделать как в примере». Используйте встроенный промпт для преобразования.

## 8. Ограничения программы

- **Картографическая подложка** — используется только современная подложка OpenStreetMap. Для исторической геовизуализации необходимо учитывать наложение исторических локаций на современную карту (изменившиеся названия, исчезнувшие населённые пункты). В будущих версиях планируется поддержка исторических подложек.
- **Браузеры** — тестировалось в Chrome и Яндекс.Браузере. В старых версиях Edge возможны проблемы с кодировкой.
- **Размер текста** — искусственных ограничений нет, но при очень больших объёмах производительность может зависеть от железа пользователя.
- **Экспортированная HTML-карта** — требует интернета для подгрузки подложки.
