# SOVA / СОВА — Текст и Карта

## 📖 О проекте

**СОВА** помогает исследователям, преподавателям и всем, кто работает с текстами, превращать упоминания мест в интерактивные карты с таймлайном. Программа подходит для работы с историческими документами, путевыми заметками, художественной литературой, новостными материалами и любыми другими текстами, содержащими географические привязки.

Программа работает полностью локально в браузере, не отправляет ваши данные на внешние серверы и не требует регистрации. Интернет нужен только для подгрузки картографической подложки — после первой загрузки карта может работать офлайн.

СОВА не привязана к конкретной нейросети: вы можете использовать любой ИИ-сервис для первичной разметки текста, а саму программу — как рабочую среду для проверки, редактирования и визуализации. Весь функционал доступен и вручную — ИИ лишь ускоряет рутинные этапы.

Проект развивается в рамках творческого объединения **Matrix Mentularia**, занимающегося разработкой инструментов для Digital Humanities и работы с культурным наследием.

## 🚀 Быстрый старт

СОВА работает как один HTML-файл в браузере, установка не требуется.

1. Скачайте `SOVA_0.4.html` из этого репозитория, либо пройдите по ссылке https://matrixmentularia.github.io/SOVA/SOVA_0.4.html  
2. Откройте в любом современном браузере (Chrome, Яндекс.Браузер, Firefox)
3. **Нажмите на кнопку "Промпты", скопируйте промпт "РУКОВОДСТВО", вставьте в ваш ИИ-чат, далее следуйте указаниям.**
4. Загрузите `.txt` с текстом и `sova.json` с разметкой
5. Проверьте топонимы во вкладке «Текст»
6. Загрузите координаты как «Данные.json»
7. Перейдите во вкладку «Карта» и постройте визуализацию
8. Экспортируйте результат

Подробная инструкция — в файле [TUTORIAL.md](TUTORIAL_SOVA.md) в этом репозитории.

## ✨ Возможности

- Три режима работы: только текст, только таблица, текст + разметка
- Синхронная прокрутка текста и таблицы, клик-навигация между ними
- Ручное выделение и добавление топонимов прямо в тексте
- Редактирование координат перетаскиванием маркеров на карте
- Анимация по времени: режимы «События» и «Время» с настраиваемым шагом
- Линии между датированными точками на карте
- Экспорт автономной HTML-карты для встраивания на сайт
- Итеративное сохранение: каждый экспорт — отдельная версия проекта

## 🛠️ Дополнительные инструменты

Для эффективной работы с СОВОй вам понадобятся:

- **Блокнот** (или любой текстовый редактор) — для сохранения фрагментов текста и JSON-файлов от ИИ
- **ИИ-ассистент** (Qwen, Kimi, DeepSeek или любой другой) — для первичной разметки текста, геокодирования и таймингов

Промпты для ИИ встроены в программу — просто скопируйте нужный промпт и отдайте его вместе с текстом в нейросеть.

## 📦 Форматы данных

- `.txt` — исходный текст
- `.markup.sova.json` — разметка топонимов
- `project.sova.json` — проект (полный)
- `clear.sova.json` — проект без отклонённых данных
- `data.sova.json` — геоданные
- `time.sova.json` — метки времени
- `map_export.sova.html` — экспортированная интерактивная карта

## ⚠️ Ограничения

- **Картографическая подложка** — программа использует только современную подложку OpenStreetMap. Для исторической геовизуализации необходимо учитывать наложение исторических локаций на современную карту (например, изменившиеся названия, исчезнувшие населённые пункты). В будущих версиях планируется найти решение.
- **Браузеры** — тестировалось в Chrome и Яндекс.Браузере. В старых версиях Edge возможны проблемы с кодировкой.
- **Размер текста** — искусственных ограничений нет, но при объёмах более 350 000 символов производительность может зависеть от ресурсов на стороне пользователя.
